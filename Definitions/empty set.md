For a statement $P(x)$ that is false for every possible value of $x$, nothing in the universe can pass the elementhood test for the truth set of $P(x)$, and so this [[truth set]] mush have no elements. Because a set is completely  determined once its elements have been specified, there is only one set that has no elements. [[Axiom of extensionality]] It is called the empty set, or the null set, and is often denoted $\emptyset$. For example, $\{ x\in \mathbb{Z}\mid x \neq x \}=\emptyset$. Since the empty set has no elements, the statement $x \in \emptyset$ is an example of a statement that is always false, no matter what $x$ is.
