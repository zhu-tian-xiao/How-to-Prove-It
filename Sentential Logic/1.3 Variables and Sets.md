# Variables and Sets
In mathematical reasoning it is often necessary to make statements about objects that are represented by letters callled **variables**.

$P(x)$, to stress that this is a statement **about** $x$.

A statement might even contain several variables that stand for different kinds of objects. For example,  "$x$ has $y$ children," the variable $x$ stands for a person, and $y$ stands for a number.

Statements involving variables can be combined using connectives, just like statements without variables.

A set is a collection of objects. The objects in the collection are called the elements of the set.

We use the symbol $\in$ to mean is an element of.

A set is completely determined once its elements have been specified. Thus two sets that have exactly the same elements are always equal.

$B={2,3,5,7,11,13,17,\dots}$
$B=\{ x\mid x \text{ is a prime number.} \}$

This is read "$B$ is equal to the set of all $x$ such that $x$ is a prime number,"

You should think of the statement "$x$ is a prime number" as an **elementhood test** for the set. Any value of $x$ that makes the statement come out true passes the test and is an element of the set. Anything else fails the test and is not an element.

If a set has been defined using an elementhood test, then that test can be used to determin whether or not something is an element of the set.

For any number $y$, to determine whether or not $y\in\{x \mid x^{2}<9\}$, we just check whether or not $y^2 <9$. In fact, we could think of the statement $y\in \{ x\mid x^2<9 \}$ as just a roundabout way of saying $y^2<9$.

We say that in the statement $y\in \{ x\mid x^2<9 \}$, $y$ is a **free** variable, whereas $x$ is a bound variable(or a **dummy** variable). The free variables in a statement stand for objects that the statement says something about. Plugging in different values for a free variable affects the meaning of a statement and may change its truth table. Bound variables, on the other hand, are simply letters that are of as a convenience to help express an idea and should not be thought of as standing for any particular object. A bound variable can always be replaced by a new variable without changing the meaning of the statement, and often the statement can be rephrased so that the bound variables are eliminated altogether.

We could say that the notation $\{ x\mid\dots \}$ binds the variable $x$.

In general, the statement $y\in \{ x\mid P(x) \}$ means the same thing as $P(y)$, which is a statement about $y$ but not $x$. Similarily, $y\not\in \{ x\mid P(x) \}$ means the same thing as $\neg P(y)$.

Example 1.3.3. What do these statements mean? What are the free variables in each statement?

1.$a+b\not\in \{ x \mid x \text{ is a even number} \}$
2.$y\in \{ x\mid x \text{ is divisible by }w \}$
3.$2\in \{ w\mid 6 \not\in \{ x \mid x \text{ is divisible by }w \} \}$

1.Both $a$ and $b$ are free variables, but $x$ is a bound variable.
2.This statement says that $y$ is divisible by $w$. Both $y$ and $w$ are free variables, but $x$ is a bound variable. The statement is true for some values of $y$ and $w$ and false for others.
3.$6\not\in \{ x\mid x \text{ is divisible by }w \}$ means the same thing as  "$6$ is not divisible by $w$." Then we get $2\in \{ w\mid 6 \text{ is not divisible by }w \}$. This means the same thing as "$6$ is not divisible $2$." Thus, the statement has no free variables, and both $x$ and $w$ are bound variables.

Definition 1.3.4. The truth set of a statement $P(x)$ is the set of all values of $x$ that make the statement $P(x)$ true. In other words, It is the set defined by using the statement $P(x)$ as an elementhood test: $\{ x\mid P(x) \}$.


Example 1.3.5. What are the truth sets of the following statements?
1.Shakespeare wrote $x$.
2.$n$ is an even prime number.

1.$\{ x \mid \text{Shakespeare wrote }x\}$
2.$\{ n\mid n\text{ is an even prime number} \}$.  Because the only even prime number is $2$, this is the set $\{ 2 \}$.

Suppose $A$ is the truth set of a statement $P(x)$. According to the definition of truth set, this means that $A=\{ x\mid P(x) \}$. We've already seen that for any object $y$, the statement $y\in \{ x\mid P(x) \}$ means the same thing as $P(y)$. Substituting in $A$ for $\{ x\mid P(x) \}$, it follows that $y\in A$ means the same thing as $P(y)$. In general, if $A$ is the truth set of $P(x)$, then to say that $y\in A$ means the same thing as saying $P(y)$.

When a statement contains free variables, it it often clear from context that these variables stand for objects of a particular kind.  The set of all objects of this kind - in other words, the set of all possible values for the variables - is called the **universe of discourse** for the statement, and we say that the variable **range over** this universe.

important sets often as universes of discourse

$\mathbb{R}=\{ x\mid x\text{ is a real number} \}$
$\mathbb{Q}=\{ x\mid x\text{ is a rational number} \}$
$\mathbb{Z}=\{ x\mid x\text{ is an integer} \}=\{\dots, -3, -2, -1, 0, 1, 2, 3, \dots\}$
$\mathbb{N}=\{ x\mid x \text{ is a natrual number} \}=\{ 0, 1, 2, 3, \dots \}$

$\mathbb{R^+}=\{ x\mid x \text{ is a positive real number} \}$
$\mathbb{Z^-}=\{ x\mid x\text{ is a negative integer} \}$

Although the universe of discourse can usually be determined from context, it is sometimes useful to identify it explicitly. Consider a statement $P(x)$ with a free variable $x$ that ranges over a universe $U$. We could spefify the truth set of $P(x)$ explicitly as $\{ x\in U\mid P(x) \}$; this is read "the set of all $x$ in $U$ such that $P(x)$." This notation indicates that only elements of $U$ are to be considered for elementhood in this truth set, and among elements of $U$, only those that pass the elmenthood test $P(x)$ will actually be in the truth set.

Sometimes this explicit notation is used not to specify the universe of discourse but to restrict attention to just a part of the universe. 

The statement $y\in \{ x\in \mathbb{R+}\mid x^2<9 \}$ means the same thing as $y\in \mathbb{R+}\land y^2<9$. In general, $y\in \{ x\in A\mid P(x) \}$ means the same thing as $y\in A\land P(y)$.

Suppose $P(x)$ is a statement containing a free variable $x$ that ranges over a universe $U$. It should be clear that if $P(x)$ come out true for every value of $x$ in $U$, then will be the whole universe $U$.
Since $P\lor \neg P$ is a tautology, the statemnet $P(x)\lor \neg P(x)$ will be true for every $x\in U$, no matter what statement $P(x)$ stands for or what the universe $U$ is, and therefore the truth set of the statement $P(x) \lor \neg P(x)$ will be $U$.

For a statement $P(x)$ that is false for every possible value of $x$, nothing in the universe can pass the elementhood test for the truth set of $P(x)$, and so this truth set mush have no elements. Because a set is completely  determined once its elements have been specified, there is only one set that has no elemnents. It is called the empty set, or the null set, and is often denoted $\emptyset$. For example, $\{ x\in \mathbb{Z}\mid x \neq x \}=\emptyset$.

1.Analyse the logical forms of the following statements:
(a) $3$ is a common divisor of $6, 9,$ and $15$.
(b) $x$ is divisible by both $2$ and $3$ but not $4$.
(c) $x$ and $y$ are natural numbers, and exactly one of them is prime.

(a) Let $P(x)$: "$3$ is a divisor of $x$." $P(6) \land P(9) \land P(15)$.

(b) Let $P(x,y)$: "$x$ is divisible by $y$." $P(x,2) \land P(x,3) \land \neg P(x,4)$.

(c) Let $P(x)$: "$x$ is natural number." $Q(x)$: $x$ is prime. $P(x) \land P(y) \land (Q(x) \lor Q(y))\land \neg(Q(x)\land Q(y))$.

2.Analyse the logical forms of the following statements:
(a) $x$ and $y$ are men, and either $x$ is taller than $y$ or $y$ is taller than $x$.
(b) Either $x$ or $y$ has brown eyes, and either $x$ or $y$ has red hair.
(c) Either $x$ or $y$ has both brown eyes and red hair.

(a) Let $P(x)$: "$x$ is man." $Q(x,y)$: "$x$ is taller than $y$." $P(x)\land P(y)\land[(Q(x,y)\land \neg Q(y,x))\lor(Q(y,x)\land \neg Q(x,y))]$.
(b) Let $P(x)$: "$x$ has brown eyes." $Q(x)$: "$x$ has red hair." $(P(x)\lor P(y))\land(Q(x)\lor Q(y))$.

(c) Let $P(x)$: "$x$ has brown eyes." $Q(x)$: "$x$ has red hair." 
$(P(x)\land Q(x)) \lor(P(y)\land Q(y))$.

5.Simplify the following statements. Which variables are free and which are bound? If the statement has no free variables, say whether it is true or false.
(a) $-3\in \{ x\in \mathbb{R}\mid 13-2x>1 \}$.
(b) $4\in \{ x\in \mathbb{R^-}\mid 13-2x>1 \}$.
(c) $5\not\in \{ x\in \mathbb{R}\mid 13-2x>c \}$.

(a) is equivalent to $(-3\in \mathbb{R}) \land (13-2\cdot(-3)>1)$.
$x$ is bound. The statement is true.

(b) is equivalent to $(4\in \mathbb{R^-})\land (13-2\cdot(4)>1)$.
$x$ is bound. The statement is false because $4$ is positive.

(c) is equivalent to $(5\not\in \mathbb{R})\lor (13-2\cdot(5)\leq c)$,
which is equivalent to $(5\not\in \mathbb{R})\lor (c\geq 3)$.
$x$ is bound, $c$ is free.

9.What are the truth sets of the following statements? List a few elements of the truth set if you can.
(a) $x$ is a real number and $x^2-4x+3=0$.
(b) $x$ is a real number and $x^2-2x+3=0$.
(c) $x$ is a real number and $5\in \{ y\in \mathbb{R}\mid x^2+y^2<50 \}$.

(a) $x^2-4x+3=(x-1)(x-3)=0$. $x=1\lor x=3$. The truth set is $\{ 1,3 \}$.
(b) $x^2-2x+3=(x-1)^2+2=0$. The truth set is $\emptyset$.
(c) $5\in \{ y\in \mathbb{R}\mid x^2+y^2<50 \}$ is equivalent to $(5\in \mathbb{R})\land (x^2+5^2<50)$,
which is equivalent to $x^2<25$. The truth set is $\{ x\in \mathbb{R}\mid x^2<25 \}$.
