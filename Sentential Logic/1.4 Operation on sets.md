# Operation on sets
Definitions 1.4.1. The intersection of two sets $A$ and $B$ is the set $A\cap B$ defined as follows:
$$
A\cap B=\{ x\mid  x\in A \land x\in B \}
$$.
The Union of $A$ and $B$ is the set $A\cup B$ defined as follows:
$$
A\cup B=\{ x\mid  x\in A\land x\in B \}
$$.
The difference of $A$ and $B$ is the set $A$ and $B$ is the set $A \setminus B$ defined as follows:
$$
A\setminus B=\{ x\in A\land x\not\in B \}
$$
.
Remember that the statements that appear in these definitions are **elementhood tests**.

$A\triangle B=(A\setminus B)\cup(B\setminus A)=(A\cup B)\setminus(A\cap B)$.

If $A$ is the truth set of a statement $P(x)$ and $B$ is the truth set of $Q(x)$, $x\in A$ means the same thing as $P(x)$, $x\in B$ means the same thing as $Q(x)$.
The truth set of $P(x)\land Q(x)$ is $\{ x\mid P(x)\land Q(x) \}=\{ x\mid x\in A\land x\in B \}=A\cap B$.

The truth set of $P(x) \lor Q(x)$ is $\{ x\mid P(x)\lor Q(x) \}=\{ x\mid x\in A\lor x\in B \}=A\cup B$.

The truth set of $\neg P(x)$ will consist of those elements of the universe for which $P(x)$ is false. $\{ x\in U\mid \neg P(x) \}=\{ x\mid x\in U\land \neg P(x) \}=\{ x\mid x\in U\land x\not\in A \}=U\setminus A$. 

The set theory operations $\cap,\cup$ and $\setminus$ are related to the logical connectives $\land,\lor$ and $\neg$.

The logical connectives can only be useed to combine statements, whereas the set theory operations must be used to combine set.

$x\in A\cap B$ means that $x\in A\land x\in B$.

Example 1.4.4. Analyze the logical forms of the following statements:
1.$x\in A\cap(B\cup C)$.
2.$x\in A\setminus(B\cap C)$.
3.$x\in(A\cap B)\cup(A\cap C)$

1.$x\in A\cap(B\cup C)$ is equivalent to $x\in A\land x\in(B\cup C)$,
which is equivalment to $x\in A\land(x\in B\lor x\in C)$.

2.$x\in A\setminus(B\cap C)$ is equivalent to $x\in A\land \neg(x\in B\cap C)$,
which is equivalent to $x\in A\land \neg(x\in B\land x\in C)$.

3.$x\in(A\cap B)\cup(A\cap C)$ is equivalent to $x\in(A\cap B)\lor x\in(A\cap C)$,
which is equivalent to $(x\in A\land x\in B)\lor(x\in A\land x\in C)$.

$x\in A\land(x\in B\lor x\in C)$ is equivalent to $(x\in A\land x\in B)\lor(x\in A\land x\in C)$.
So $x\in A\cap(B\cup C)$ is equivalent to $x\in(A\cap B)\cup(A\cap C)$,
$\{ x\mid x\in A\cap(B\cup C) \}=\{ x\mid x\in(A\cap B)\cup(A\cap C) \}$,
$A\cap(B\cup C)=(A\cap B)\cup(A\cap C)$.

$A\cup(B\cap C)=(A\cup B)\cap(A\cup C)$.

$x\in A\setminus(B\cap C)$ is equivalent to $x\in A\land \neg(x\in B\land x\in C)$.
which is equivalent to $x\in A\land (x\not\in B\lor x\not\in C)$,

Definition 1.4.5. Suppose $A$ and $B$ are sets. We will say that $A$ is subset of $B$ if every element of $A$ is also an element of $B$. We write $A\subseteq B$ to mean that $A$ is a subset of $B$. $A$ and $B$ are said to be disjoint if they have no elements in common. Note that this is the same as saying that the set of elements they have in common is the empty  set, or in other words $A\cap B=\emptyset$.


Theorem 1.4.7.
For any sets $A$ and $B$, $(A\cup B)\setminus B\subseteq A$.

Proof. We must show that if something is an elements of $(A\cup B)\setminus B$, then it must also be an element of $A$, so suppose that $x\in(A\cup B)$. This  means that $x\in A\cup B$ and$x\not\in B$, or in other words $x \in A\lor x \in B$ and $x\not\in B$. But notice that these statements have the logical form $P\lor Q$ and $\neg Q$, we can conclude that $x \in A$ must be true. So $(A\cup B)\setminus B\subseteq A$.

(b) $C\setminus(A\triangle B)=(A\cap C)\triangle(C\setminus B)$.
(c) $(B\setminus A)\triangle C=(A\triangle C)\triangle(A\cup B)$.

(a)
$x \in(C\setminus A)\triangle(C\setminus B)$ is equivalent to $(x \in C\setminus A\land x\not\in C\setminus B)\lor(x\not\in C\setminus A\land x \in C\setminus B)$,
which is equivalent to $(x \in C\land x\not\in A\land(x\not\in C\lor x \in B))\lor((x\not\in C\lor x \in A)\land(x \in C\land x\not\in B))$,
which is equivalent to $(x\not\in A\land x \in B\land x \in C)\lor(x \in A\land x \not\in B\land x \in C)$,
which is equivalent to $x \in C\land((x \not\in A\land x \in B)\lor(x \in A \land x\not\in B))$,
which is euqivalent to $x \in (A\triangle B)\cap C$.

(b)
$x \in(A\cap C)\triangle(C\setminus B)$ is equivalent to $(x \in A\cap C\land x \not\in C\setminus B)\lor(x\not\in A\cap C\land x \in C\setminus B)$,
which is equivalent to $[x \in A\land x \in C\land (x \not\in C\lor x \in B)]\lor[(x\not\in A\lor x\not\in C)\land(x \in C\land x \not\in B)]$,
which is equivalent to $(x \in A\land x \in B\land x \in C)\lor(x\not\in A\land x\not\in B\land x \in C)$,
which is equivalent to $x \in C\land[(x \in A\land x \in B)\lor(x\not\in A\land x\not\in B)]$
which is equivalent to $x \in C\land\neg[\neg(x \in A\land x \in B)\land(x \in A\lor x \in B)]$,
which is equivalent to $x \in C \setminus(A\triangle B)$.

(c)
$(A\triangle C)\triangle(A\cup B)=(A\triangle(A\cup B))\triangle C$.

Next we need to prove $A\triangle(A\cup B)=B\setminus A$.

$x \in A\triangle(A\cup B)$ is equivalent to $(x \in A\land x\not\in A\cup B)\lor(x\not\in A\land x \in A\cup B)$,
which is equivalent to $(x \in A\land x\not\in A\land x\not\in B)\lor[x\not\in A\land(x \in A\lor x \in B)]$,
which is equivalent to $x \not\in A\land x \in B$,
which is equivalent to $x \in B\setminus A$.

Then $(B\setminus A)\triangle C=(A\triangle C)\triangle(A\cup B)$.
