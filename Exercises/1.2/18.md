Suppose the conclusion of an argument is a tautology. What can you conclude about the validity of the argument? What if the conclusion is a contradiction? What if one of the premises is either a  tautology or a contradiction?

---
If the conclusion of an argument is a tautology, the argument is valid. If the conclusion of an argument is a contradiction, the argument is either valid or invalid. If one of the premises is a tautology, the argument is either valid or invalid. If one of the premises is a contradiction, the argument is valid.
