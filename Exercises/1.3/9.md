What are the truth sets of the following statements? List a few elements of the truth set if you can.

(a) $x$ is a real number and $x^2-4x+3=0$.

(b) $x$ is a real number and $x^2-2x+3=0$.

(c) $x$ is a real number and $5\in \{ y\in \mathbb{R}\mid x^2+y^2<50 \}$.

---

(a) $x^2-4x+3=(x-1)(x-3)=0$. $x=1\lor x=3$. The truth set is $\{ 1,3 \}$.

(b) $x^2-2x+3=(x-1)^2+2=0$. The truth set is $\emptyset$.

(c) $5\in \{ y\in \mathbb{R}\mid x^2+y^2<50 \}$ is equivalent to $(5\in \mathbb{R})\land (x^2+5^2<50)$, which is equivalent to $x^2<25$. The truth set is $\{ x\in \mathbb{R}\mid x^2<25 \}$.
