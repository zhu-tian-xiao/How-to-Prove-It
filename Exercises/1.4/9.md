For each of the following sets , write out(using logical symbols) what it means for an object $x$ to be an element of the set. Then determine which of these sets  must be equal to each other by determining which  statements are equivalent.

(a) $(A\setminus B)\setminus C$.

(b) $A\setminus(B\setminus C)$.

(c) $(A\setminus B)\cup(A\cap C)$.

(d) $(A\setminus B)\cap(A\setminus C)$.

(e) $A\setminus(B\cup C)$.

---
(a) is equivalent to $(x \in A \land x \not\in B)\land x \not\in C$, which is equivalent to $x \in A \land \neg(x \in B\lor x \in C)$, which is equivalent to $x \in A \land x \not\in B\cup C$, which is equivalent to $x \in A\setminus(B\cup C)$. (a) is equivalent to (e).

(b) is equivalent to $x \in A \land \neg(x \in B \land x\not\in C)$, which is equivalent to $x \in A \land (x \not\in B\lor x \in C)$, which is equivalent to $(x \in A \land x \not\in B) \lor(x \in A \land x \in C)$, which is equivalent to $x \in A\setminus B \lor x \in A\cap C$, which is equivalent to $x \in(A\setminus B)\cup(A\cap C)$. (b) is equivalent to (c).

(a) is equivalent to $(x \in A \land x \not\in B)\land x \not\in C$, which is equivalent to $(x \in A \land x \not\in B)\land(x \in A \land x \not\in C)$. (a) is equivalent to (d).

So (a), (d), (e) are equivalent. (b) and (c) are equivalent.
