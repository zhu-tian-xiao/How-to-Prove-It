Verify the identities in [[Exercises/1.4/4|4]] by writing out(using logical symbols) what it means for an object $x$ to be an element of each set and then using logical equivalences.

![[Exercises/1.4/4|4]]



(a) $x \in A\setminus(A\cap B)$ is equivalent to $x \in A \land x\not\in A\cap B$, which is equivalent to $x \in A \land \neg (x \in A\land x \in B)$, which is equivalent to $x \in A \land (x \not\in A \lor x \not\in B)$, which is equivalent to $(x \in A\land x\not\in A)\lor(x \in A\land x\not\in B)$, which is equivalent to $x \in A\land x\not\in B$.
So $A\setminus(A\cap B)=A\setminus B$.

(b) $x \in A\cup(B\cap C)$ is equivalent to $x \in A \lor x \in B\cap C$, which is equivalent to $x \in A \lor(x \in B \land x \in C)$, which is equivalent to $(x \in A \lor x \in B)\land (x \in A \lor x \in C)$. So $A\cup(B\cap C)=(A\cup B)\cap(A\cup C)$.
