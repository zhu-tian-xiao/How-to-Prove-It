Verify the identities in [[Exercises/1.4/6|6]] by writing out(using logical symbols) what it means for an object $x$ to be an element of each set and then using logical equivalences.

![[Exercises/1.4/6|6]]

(a) $x \in(A\cup B)\setminus C$ is equivalent to $x \in A\cup B$ and $x\not\in C$, which is equivalent to $(x \in A\lor x \in B)\land x\not\in C$, which is equivalent to $(x \in A\land x\not\in C)\lor(x \in B\land x\not\in C)$, which is equivalent to $x \in(A\setminus C)\cup(B\setminus C)$. So $(A\cup B)\setminus C=(A\setminus C)\cup(B\setminus C)$.

(b) $x \in A\cup(B\setminus C)$ is equivalent to $x \in A\lor(x \in B\land x\not\in C)$, which is equvialent to $(x \in A\lor x \in B)\land(x \in A\lor x\not\in C)$, which is equivalent to $(x \in A\cup B)\land \neg(x \not\in A\land x \in C)$, which is equivalent to $x \in (A\cup B)\setminus(C\setminus A)$. So $A\cup(B\setminus C)=(A\cup B)\setminus(C\setminus A)$.
