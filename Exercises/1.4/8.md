Use any method you wish to verify the following identities:

(a) $(A\setminus B)\cap C=(A\cap C)\setminus B$.

(b) $(A\cap B)\setminus B=\emptyset$.

(c) $A\setminus(A\setminus B)=A\cap B$.

---
(a) $x \in(A\setminus B)\cap C$ is equivalent to $(x \in A \land x\not\in B)\land x \in C$, which is equivalent to $(x \in A \land x \in C)\land x \not\in B$. So $(A\setminus B)\cap C=(A\cap C)\setminus B$.

(b) $x \in(A\cap B)\setminus B$ is equivalent to $(x \in A\land x \in B)\land x \not\in B$, which is equivalent to $x \in A \land (x \in B\land x \not\in B)$. So $x \in(A\cap B)\setminus B$ is false for every $x$ in $U$, there is no element in $(A\cap B)\setminus B$, $(A\cap B)\setminus B=\emptyset$.

(c) $x \in A\setminus(A\setminus B)$ is equivalent to $x \in A \land \neg(x\in A\setminus B)$, which is equivalent to $x \in A\land \neg(x \in A \land x \not\in B)$, which is equivalent to $x \in A \land (x\not\in A \lor x \in B)$, which is equivalent to $(x \in A  \land x\not\in A)\lor(x \in A \land x \in B)$, which is equivalent to $x \in A \land x \in B$. So $A\setminus(A\setminus B)=A\cap B$.
