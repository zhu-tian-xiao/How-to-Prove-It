# Operation on sets
Definitions 1.4.1.  [[Definitions/intersection]] [[union]] [[difference]] [[symmetric difference]]



If $A$ is the truth set of a statement $P(x)$ and $B$ is the truth set of $Q(x)$, $x\in A$ means the same thing as $P(x)$, $x\in B$ means the same thing as $Q(x)$.

The truth set of $P(x)\land Q(x)$ is $\{ x\mid P(x)\land Q(x) \}=\{ x\mid x\in A\land x\in B \}=A\cap B$.

The truth set of $P(x) \lor Q(x)$ is $\{ x\mid P(x)\lor Q(x) \}=\{ x\mid x\in A\lor x\in B \}=A\cup B$.

The truth set of $\neg P(x)$ will consist of those elements of the universe for which $P(x)$ is false. $\{ x\in U\mid \neg P(x) \}=\{ x\mid x\in U\land \neg P(x) \}=\{ x\mid x\in U\land x\not\in A \}=U\setminus A$. 

The set theory operations $\cap,\cup$ and $\setminus$ are related to the logical connectives $\land,\lor$ and $\neg$.

The logical connectives can only be used to combine statements, whereas the set theory operations must be used to combine sets.

Example 1.4.4.Analyze the logical forms of the following statements:
1.$x\in A\cap(B\cup C)$.
2.$x\in A\setminus(B\cap C)$.
3.$x\in(A\cap B)\cup(A\cap C)$

1.$x\in A\cap(B\cup C)$ is equivalent to $x\in A\land x\in(B\cup C)$, which is equivalment to $x\in A\land(x\in B\lor x\in C)$.

2.$x\in A\setminus(B\cap C)$ is equivalent to $x\in A\land \neg(x\in B\cap C)$, which is equivalent to $x\in A\land \neg(x\in B\land x\in C)$.

3.$x\in(A\cap B)\cup(A\cap C)$ is equivalent to $x\in(A\cap B)\lor x\in(A\cap C)$, which is equivalent to $(x\in A\land x\in B)\lor(x\in A\land x\in C)$.

$x\in A\land(x\in B\lor x\in C)$ is equivalent to $(x\in A\land x\in B)\lor(x\in A\land x\in C)$. So $x\in A\cap(B\cup C)$ is equivalent to $x\in(A\cap B)\cup(A\cap C)$, $\{ x\mid x\in A\cap(B\cup C) \}=\{ x\mid x\in(A\cap B)\cup(A\cap C) \}$, $A\cap(B\cup C)=(A\cap B)\cup(A\cap C)$.

$A\cup(B\cap C)=(A\cup B)\cap(A\cup C)$.

$x\in A\setminus(B\cap C)$ is equivalent to $x\in A\land \neg(x\in B\land x\in C)$, which is equivalent to $x\in A\land (x\not\in B\lor x\not\in C)$, which is equivalent to $(x\in A\land x\not\in B)\lor(x\in A\land x\not\in C)$, which is equivalent to $(x\in A\setminus B)\lor(x\in A\setminus C)$, which is equivalent o $x\in(A\setminus B)\cup(A\setminus C)$.

15.Use any method you wish to verify the following identities:
(a) $(A\triangle B)\cup C=(A\cup C)\triangle(B\setminus C)$.
(b) $(A\triangle B)\cap C=(A\cap C)\triangle(B\cap C)$.
(c) $(A\triangle B)\setminus C=(A\setminus C)\triangle(B\setminus C)$.

(a) $x \in (A\cup C)\triangle (B \setminus C)$ is equivalent to $(x \in A \cup C\land x\not\in B\setminus C)\lor(x \not\in A\cup C\land x \in B\setminus C)$,
which is equivalent to $[(x \in A\lor x \in C)\land(x \not\in B \lor  x \in C)]\lor(x \not\in A\land x\not\in C\land x \in B \land x \not\in C)$,
which is equivalent to $[x \in C\lor(x \in A\land x\not\in B)]\lor(x \not\in A\land x\not\in B\land x\not\in C)$,
which is equivalent to $[x \in C\lor (x \in A\land x\not\in B)\lor(x\not\in A\land x \in B)]\land[x \in C\lor(x \in A\land x\not\in B)\lor x\not\in C]$,
which is equivalent to $x \in C\lor(x \in A\land x \not\in B) \lor(x\not\in A\land x \in B)$,
which is equivalenet to $x \in (A\triangle B)\cup C$.
So $(A\triangle B)\cup C=(A\cup C)\triangle(B\setminus C)$.

(b) $x \in(A\cap C)\triangle (B\cap C)$ is equivalent to $(x \in A\cap C\lor x \in B\cap C)\land \neg(x \in A\cap C\land x \in B\cap C)$,
which is equivalent to $[(x \in A\land x \in C)\lor(x \in B\land x \in C)]\land(x\not\in A\cap C\lor x\not\in B\cap C)$,
which is equivalent to $x \in C\land(x \in A \lor x \in B)\land(x \not\in A\lor x\not\in C\lor x\not\in B\lor x\not\in C)$,
which is equivalent to $x \in C\land(x \in A\lor x \in B)\land (x\not\in A\lor x\not\in B\lor x\not\in C)$,
which is equivalent to $[x \in C\land(x \in A\lor x \in B)\land (x\not\in A\lor x\not\in B)]\lor[x \not\in C\land x \in C\land(x \in A\lor x \in B)]$
which is equivalent to $x \in C\land(x \in A\lor x \in B)\land (x\not\in A\lor x\not\in B)$.
So $(A\triangle B)\cap C=(A\cap C)\triangle(B\cap C)$.

$(x \in A\setminus C\land x\not\in B\setminus C)\lor(x\not\in A\setminus C\land x \in B\setminus C)$ is equivalent to $(x \in A\land x \not\in C\land x\not\in B)\lor(x \in B\land x\not\in C\land x \not\in A)$,
which is equivalent to $x\not\in C\land[(x \in A\land x\not\in B)\lor(x \in B\land x \not\in A)]$.
