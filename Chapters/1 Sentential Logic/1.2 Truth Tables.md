# Truth Tables
When we evaluate the truth or falsity of a statement, we assign to it one of the labels **true** or **false**, and this label is called its **truth value**.


| $P$ | $Q$ | $P\land Q$ |
| --- | --- | ---------- |
| F   | F   | F          |
| F   | T   | F          |
| T   | F   | F          |
| T   | T   | T          |

| $P$ | $\neg P$ |
| --- | -------- |
| F   | T        |
| T   | F        |

How to represent an argument symbolically?

$$
\frac{\begin{align}
& P\lor Q \\
& \neg P \\

\end{align}}{
\therefore Q
}
$$

[[De Morgan's laws]]
$\neg(P\land Q)$ is equivalent to $\neg P\lor \neg Q$
$\neg(P\lor Q)$ is equivalent to $\neg P\land \neg Q$

[[Commutative laws]]
$P\land Q$ is equivalent to $Q\land P$
$P\lor Q$ is equivalent to $Q\lor P$

[[Associative laws]]
$P\land(Q\land R)$ is equivalent to $(P\land Q)\land R$
$P\lor(Q\lor R)$ is equivalent to $(P\lor Q)\lor R$

[[Idempotent laws]]
$P\land P$ is equivalent to $P$
$P\lor P$ is equivalent to $P$

[[Distributive laws]]
$P\land(Q\lor R)$ is equivalent to $(P\land Q)\lor(P\land R)$
$P\lor(Q\land R)$ is equivalent to $(P\lor Q)\land(P\lor R)$

[[Absorption laws]]
$P\lor(P\land Q)$ is equivalent to $P$
$P\land(P\lor Q)$ is equivalent to $P$

[[Double Negation law]]
$\neg \neg P$ is equivalent to P

Formulas that are always true, such as $P\lor \neg P$, are called [[tautologies]]. Similarly, formulas that are always false are called [[contradiction]]s.

[[Tautology laws]]
$P\land$(a tautology) is equivalent to $P$.
$P\lor$(a tautology) is a tautology.
$\neg$(a tautology) is a tautology.

[[Contradiction laws]]
$P\land$(a contradiction) is a contradition.
$P\lor$(a contradiction) is equivalent to $P$.
$\neg$(a contradiction) is equivalent to tautology.

8.Use truth tables to determine which of the following formulas are equivalent to each other:
(a) $(P\land Q)\lor(\neg P\land \neg Q)$
(b) $\neg P\lor Q$
(c) $(P\lor \neg Q)\land(Q\lor \neg P)$
(d) $\neg(P\lor Q)$
(e) $(Q\land P)\lor \neg P$

$(P\land Q)\lor(\neg P\land \neg Q)$ is equivalent to $[(P\land Q)\lor \neg P]\land[(P\land Q)\lor \neg Q]$,
which is equivalent to $(Q\lor \neg P)\land(P\lor\neg Q)$,
so (a) is equivalent to (c)

$(Q\land P)\lor \neg P$ is equivalent to $Q\lor \neg P$,
so (b) is equivalent to (e)

(a) $(P\lor Q)\land(\neg P\lor \neg Q)$
(b) $(P\lor Q)\land (\neg P\land \neg Q)$
(c) $(P\lor Q)\lor(\neg P\lor \neg Q)$
(d) $[P\land(Q\lor \neg R)]\lor(\neg P\lor R)$

(a) neither.

| --- | --- | ----------------------------------- |
| T   | T   | F                                   |
| T   | F   | T                                   |

(b) is a contradiction.

$(\neg P\land \neg Q)$ is equivalent to $\neg(P\lor Q)$, 
so (b) is equivalent to $(P\lor Q)\land \neg(P\lor Q)$,
so (b) is contradiction.

(c),(d) tautologies.

$(P\lor Q)\lor(\neg P\land \neg Q)$ is equivalent to $(P\lor \neg P)\lor(Q\lor \neg Q)$,
so (c) is tautologies.

$P\land(Q\lor \neg R)$ is equivalent to $(P\land Q)\lor(P\land \neg R)$,
so (d) is equivalent to $(P\land Q)\lor(P\land \neg R)\lor(\neg P\lor R)$.
$(P\land \neg R)\lor(\neg P\lor R)$ is equivalent to $(P\land \neg R)\lor \neg(P\land \neg R)$,
which is a tautology.
so (d) is a tautology.

11.Use the laws stated in the text to find simpler formulas equivalent to these formulas. 
(a) $\neg(\neg P\land\neg Q)$
(b) $(P\land Q)\lor(P\land \neg Q)$
(c) $\neg(P\land \neg Q)\lor(\neg P\land Q)$

(a) is equivalent to $P\lor Q$.

(b) is equivalent to $[(P\land Q)\lor P]\land([P\land Q)\lor \neg Q]$,
which is equivalent to $P\land(P\lor \neg Q)$,
which is equivalent to $P$.

(c) is equivalent to $(\neg P\lor Q)\lor(\neg P\land Q)$,
which is equivalent to $[(\neg P\lor Q)\lor \neg P]\land[(\neg P\lor Q)\lor Q]$,
which is equivalent to $\neg P\land Q$


12.Use the laws stated in the text to find simpler formulas equivalent to these formulas. 
(a) $\neg(\neg P\lor Q)\lor(P\land \neg R)$
(b) $\neg(\neg P\land Q)\lor(P\land \neg R)$
(c) $(P\land R)\lor[\neg R\land(P\lor Q)]$

(a) is equivalent to $(P\land \neg Q)\lor(P\land \neg R)$,
which is equivalent to $P\land(\neg Q\lor \neg R)$

(b) is equivalent to $(P\lor \neg Q)\lor(P\land \neg R)$,
which is equivalent to $P\lor \neg Q$

(c) is equivalent to $[(P\land R)\lor \neg R]\land[(P\land R)\lor(P\lor Q)]$,
which is equivalent to $(P\lor \neg R)\land(P\lor Q)$,
which is equivalent to $P\lor(\neg R\land Q)$

13.Use the first De Morgan's law and the double negation law to derive the second De Morgan's law.

$\neg(P\lor Q)$ is equivalent to $\neg(\neg \neg P\lor \neg \neg Q)$,
which is equivalent to $\neg \neg(\neg P\land \neg Q)$,
which is equivalent to $\neg P\land \neg Q$.

18.Suppose the conclusion of an argument is a tautology. What can you conclude about the validity of the argument? What if the conclusion is a contradiction? What if one of the premises is either a  tautology or a contradiction?

If the conclusion of an argument is a tautology, the argument is valid. If the conclusion of an argument is a contradiction, the argument is either valid or invalid. If one of the premises is a tautology, the argument is either valid or invalid. If one of the premises is a contradiction, the argument is valid.
