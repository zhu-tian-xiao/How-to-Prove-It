Definition 4.5.1. Suppose $R$ is a relation on a set $A$. Then $R$ is called an equivalence relation on $A$ (or just an **equivalence relation** if $A$ is clear from context) if it is reflexive, symmetric, and transitive.

We saw in Example 4.3.3 that the identity relation $i_{A}$ on any set $A$ is always reflexive, symmetric and transitive. Thus, $i_{A}$ is an equivalence relation on $A$.

Another example, let $T$ be the set of all triangles, and let $C$ be the relation of congruence(全等) of triangles. In other words, $C=\{ (s,t)\in T\times T\mid{}\text{the triangle }s\text{ is congruent to the triangle }t \}$. Clearly every triangle is congruent to itself, so $C$ is reflexive. Also, if triangle $s$ is congruent to triangle $t$, then $t$ is congruent to $s$, so $C$ is symmetric; and if $r$ is congruent to $s$ and $s$ is congruent to $t$, then $r$ is congruent to $t$, so $C$ is transitive. Thus, $C$ is an equivalence relation on $T$.

Another example, let $P$ be the set of all people, and let $B=\{ (p,q)\in P\times P\mid{}\text{the person }p\text{ has the same birthday as the person }q \}$. Everyone has the same birthday as himself or herself, so $B$ is reflexive. If $p$ has the same birthday as $q$, then $q$ has the same birthday as $p$, so $B$ is symmetric. And if $p$ has the same birthday as $q$ and $q$ has the same birthday as $r$, then $p$ has the same birthday as $r$, so $B$ is transitive. Therefore $B$ is an equivalence relation.

It may be instructive to look at the relation $B$ more closely. We can think of this relation as splitting the set $P$ of all people into 366 categories, one for each possible birthday. (2月29日仅在闰年有) An ordered pair of people will be an element of $B$ if the people come from the same category, but will not be an element of $B$ if the people come from the different categories. We could think of these categories as forming a family of subsets of $P$, which we could write as an indexed family as follows. First of all, let $D$ be the set of all possible birthdays. In other words, $D=\{ \text{Jan. 1, Jan. 2, ..., Dec. 30, Dec. 31} \}$. Now for each $d\in D$, let $P_{d}=\{ p \in P\mid{}\text{the person }p\text{ was born on the day }d \}$. Then the family $\mathcal{F}=\{ P_{d}\mid{} d\in D \}$ is an indexed family of subsets of $P$. The elements of $\mathcal{F}$ are called equivalence classes for the relation $B$, and every person is an element is an element of exactly one of these equivalence classes. The relation $B$ consists of those pairs $(p,q)\in P\times P$ such that the person $p$ and $q$ are in the same equivalence class. In other words,

$$
\begin{align}
B&=\{ (p,q)\in P\times P\mid{}\exists d\in D(p \in P_{d}\text{ and }q\in P_{d}) \} \\
&=\{ (p,q)\in P\times P\mid{}\exists d\in D((p,q)\in P_{d}\times P_{d}) \} \\
&=\bigcup_{d \in D}(P_{d}\times P_{d})\text{.}
\end{align}
$$
We will call the family $\mathcal{F}$ a partition of $P$ because it breaks the set $P$ into disjoint pieces. It turn out that every equivalence relation on a set $A$ determines a partition of $A$, whose elements are the equivalence class for the equivalence relation. But before we can work out the details of why this is true, we must define the terms partition and equivalence class more carefully.

Definition 4.5.2. Suppose $A$ is a set and $\mathcal{F}\subseteq \mathscr{P}(A)$. We will say that $\mathcal{F}$ is pairwise disjoint if every pair of distinct elements of $\mathcal{F}$ are disjoint, or in other words $\forall X\in \mathcal{F}\forall Y\in \mathcal{F}(X\neq Y\to X\cap Y=\emptyset)$. (This concept was discussed in exercise 5 of Section 3.6.) $\mathcal{F}$ is called a partition of $A$ if it has the following properties:

1.$\bigcup \mathcal{F}=A$.

2.$\mathcal{F}$ is pairwise disjoint.

3.$\forall X\in \mathcal{F}(X\neq \emptyset)$.

Definition 4.5.3. Suppose $R$ is an equivalence relation on a set $A$, and $x \in A$. Then the equivalence class of $x$ with respect to $R$ is the set
$$
[x]_{R}=\{ y\in A\mid{}yRx \}\text{.}
$$
If $R$ is clear from context, then we just write $[x]$ instead of $[x]_{R}$. The set of all equivalence class of elements of $A$ is called $A$ modulo $R$, and is denoted 
$$
A / R=\{ [x]_{R}\mid{}x \in A \}=\{ X\subseteq A\mid{}\exists x \in A(X=[x]_{R}) \}\text{.}
$$
In the case of the same-birthday relation $B$, if $p$ is any person, then according to Definition 4.5.3,
$$
\begin{align}
[p]_{B}&=\{ q\in P\mid{}qBp \} \\
&=\{ q\in P\mid{}\text{the person }q\text{ has the same birthday as the person }p \}\text{.}

\end{align}

$$
For example, if John was born on August 10, then 
$$
\begin{align}
[\text{John}]_{B}&=\{ q\in P\mid{}\text{the person }q\text{ has the same birthday as John} \} \\
&=\{ q\in P\mid{}\text{the person }q\text{ was born on August 10} \}\text{.}
\end{align}
$$
In this notation we introduced earlier, this is just the set $P_{d}$, for $d=\text{August 10}$. In fact, it should be clear now that for any person $p$, if we let $d$ be $p$'s birthday, then $[p]_{B}=P_{d}$. This is in agreement with or earlier statement that the sets $P_{d}$ are the equivalence classes for the equivalence relation $B$. Let's consider one more example. Let $S$ be the relation on $\mathbb{R}$ defined as follows:
$$
S=\{ (x,y)\in \mathbb{R}\times \mathbb{R} \mid{}x-y\in \mathbb{Z}\}\text{.}
$$
Clearly for any $x \in R$, $x-x=0\in \mathbb{Z}$, so $(x,x)\in S$, and therefore $S$ is reflexive. To see that $S$ is symmetric, suppose $(x,y)\in S$. By the definition of $S$, this means that $x-y\in \mathbb{Z}$. But then $y-x=-(x-y)\in \mathbb{Z}$ too, since the negative of any integer is also an integer, so $(y,x)\in S$. Because $(x,y)$ was an arbitrary element of $S$, this shows that $S$ is symmetric. Finally, to see that $S$ is transitive, suppose that $(x,y)\in S$ and $(y,z)\in S$, Then $x-y\in \mathbb{Z}$ and $y-z\in \mathbb{Z}$. Because the sum of any integers is an integer, it follows that $x-z=(x-y)+(y-z)\in \mathbb{Z}$, so $(x,z)\in S$, as required. Thus, $S$ is an equivalence relation on $\mathbb{R}$.



Theorem 4.5.4. Suppose $R$ is an equivalence relation on a set $A$. Then $A / R$ is ax partition of $A$.

Lemma 4.5.5. Suppose $R$ is an equivalence relation on $A$. Then: 

1.For every $x \in A$, $x \in[x]$.

2.For every $x \in A$ and $y\in A$, $y\in[x]$ iff $[y]=[x]$.

1.Let $x \in A$ be arbitrary. Since $R$ is reflexive, $xRx$. Therefore, by the definition of equivalence class, $x \in[x]$.

2.($\to$) Suppose $y\in[x]$. Then by the definition of equivalence class, $yRx$. Now suppose $z\in[y]$. Then $zRy$. Since $zRy$ and $yRx$, by the transitivity of $R$ we can conclude that $zRx$, so $z\in[x]$. Since $z$ was arbitrary, this shows that $[y]\subseteq[x]$.

Now suppose $z\in[x]$, so $zRx$. We already know $yRx$, and since $R$ is symmetric we can conclude that $xRy$. Applying transitivity to $zRx$ and $xRy$, we can conclude that $zRy$, so $z\in[y]$. Therefore $[x]\subseteq[y]$, so $[x]=[y]$.

$(\leftarrow)$ Suppose $[y]=[x]$. By part 1 we know that $y\in[y]$, so since $[y]=[x]$, it follows that $y\in[x]$.

Proof of Theorem 4.5.4. To prove that $A/ R$ is a partion of $A$, we must prove the three properties in Definition 4.5.2. For the first, we must show that $\bigcup(A /R)=A$, or in other words that $\bigcup_{x \in A}[x]=A$. Now every equivalence class in $A /R$ is a subset of $A$, so it should be clear that their union is also a subset of $A$. Thus, $\bigcup(A/R)\subseteq A$, so all we need to show to finish the proof is that $A\subseteq \bigcup(A /R)$. To prove this, suppose $x \in A$. Then by Lemma 4.5.5, $x \in[x]$, and of course $[x]\in A /R$, so $x \in \bigcup(A /R)$. Thus, $\bigcup(A /R)=A$.

To see that $A /R$ is pairwise disjoint, suppose that $X$ and $Y$ are two elements of $A /R$, and $X\cap Y\neq \emptyset$. By definition of $A/R$, $X$ and $Y$ are equivalence classes, so we must  have $X=[x]$ and $Y=[y]$ for some $x, \,y\in A$. Since $X\cap Y\neq \emptyset$, we can choose some $z$ such that $z\in X\cap Y=[x]\cap[y]$. Now by Lemma 4.5.5, since $z\in[x]$ and $z\in[y]$, it follows that $[x]=[y]=[z]$. Thus, $X=Y$. This shows that if $X\neq Y$ then $X\cap Y=\emptyset$, so $A /R$ is pairwise disjoint.

Finally, for the last clause of the definition of partition, suppose $X\in A/R$. As before, this means that $X=[x]$ for some $x \in A$. Now by Lemma 4.5.5, $x \in[x]=X$, so $X\neq \emptyset$, as required.
