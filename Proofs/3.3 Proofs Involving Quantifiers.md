# Proofs Involving Quantifiers
If you can give a proof of the goal  $P(x)$ that would work no matter what $x$ was, then you can conclude that $\forall xP(x)$ must be true. To make sure that your proof would work for any value of $x$, it is important to start your proof with no assumptions about $x$. Mathematicians express this by saying that $x$ must be **arbitrary**. 

To prove a goal of the form $\forall xP(x)$:

Let $x$ stand for an arbitrary object and prove $P(x)$. The letter $x$ must be a new variable in the proof. If $x$ is already being used in the proof to stand for something, then you must choose an unused variable, say $y$, to stand for the arbitrary object, and prove $P(y)$.


Scratch work:
Before using strategy:


| Givens | Goal            |
| ------ | --------------- |
| -      | $\forall xP(x)$ |
| -      |                 |

After using strategy:

| Givens | Goal   |
| ------ | ------ |
| -      | $P(x)$ |
| -      |        |

Form of final proof:
$$
\begin{align}
&\text{Let }x \text{ be arbitrary}. \\
&\quad\text{[Proof of }P(x)\text{ goes here.]} \\
&\text{Since }x\text{ was arbitrary, we can conclude that }\forall xP(x).
\end{align}
$$

Example 3.3.1.. Suppose $A$, $B$, and $C$ are sets, and $A\setminus B\subseteq C$. Prove that $A\setminus C\subseteq B$.

Scratch work
Givens 


| Givens                    | Goal                      |
| ------------------------- | ------------------------- |
| $A\setminus B\subseteq C$ | $A\setminus C\subseteq B$ |


| Givens                    | Goal                                       |
| ------------------------- | ------------------------------------------ |
| $A\setminus B\subseteq C$ | $\forall x(x \in A\setminus C\to x \in B)$ |

$$
\begin{align}
&\text{Let }x \text{ be arbitrary}. \\
&\quad\text{[Proof of }x \in A\setminus C\to x \in B\text{ goes here.]} \\
&\text{Since }x\text{ was arbitrary, we can conclude that }\forall x(x \in A\setminus C\to x \in B) \text{, so }A\setminus C\subseteq B.
\end{align}
$$

Theorem. Suppose $A$, $B$, and $C$ are sets, and $A\setminus B\subseteq C$. Then $A\setminus C\subseteq B$.

Proof. Let $x$ be arbitrary. Suppose $x \in A\setminus C$. This means that $x \in A$ and $x\not\in C$. Suppose $x\not\in B$. Then $x \in A\setminus B$, so since $A\setminus B\subseteq C$, $x \in C$. But this contradicts the fact that $x\not\in C$. Therefore $x \in B$. Thus, if $x \in A\setminus C$ then $x \in B$. Since $x$ was arbitrary, we can conclude that $\forall x(x \in A\setminus C\to x \in B)$, so $A\setminus C\subseteq B$.

Example 3.3.2 Suppose $A$ and $B$ are sets. Prove that if $A\cap B=A$ then $A\subseteq B$.

Scratch work

| Givens      | Goal                            |
| ----------- | ------------------------------- |
| $A\cap B=A$ | $\forall x(x \in A\to x \in B)$ |

$$
\begin{align} 
&\text{Suppose }A\cap B=A. \\

&\quad\text{Let }x \text{ be arbitrary}. \\
&\quad\quad\text{Suppose }x \in A. \\ 
&\quad\quad\quad\text{[Proof of }x \in B\text{ goes here.]} \\
&\quad\quad\text{Therefore }x \in A\to x \in B. \\

&\quad\text{Since }x\text{ was arbitrary, we can conclude that }\forall x(x \in A\to x \in B)\text{, so }A\subseteq B. \\
&\text{Therefore, if }A\cap B=A\text{ then }A\subseteq B.
\end{align}
$$

Theorem. Suppose $A$ and $B$ are sets. If $A\cap B=A$ then $A\subseteq B$.

Proof. Suppose $A\cap B=A$, and suppose $x \in A$. Then since $A\cap B=A$, $x \in A\cap B$, so $x \in B$. Since $x$ was arbitrary element of $A$, we can conclude that $A\subseteq B$.

To prove a goal of the form $\exists xP(x)$:

Try to find a value of $x$ for which you think $P(x)$ will be true. Then start your proof with "Let $x=$ (the value you decided on)" and proceed to prove $P(x)$ for this value of $x$. Once again, $x$ should be a new variable. If the letter $x$ is already being used in the proof for some other purpose, then you should choose an unused variable, say $y$, and rewrite the goal in the equivalent form $\exists yP(y)$. Now proceed as before by starting your proof with "Let $y=$ (then value you decided on)" and prove $P(y)$.

Scratch work
Before using strategy:

| Givens | Goal            |
| ------ | --------------- |
| -      | $\exists xP(x)$ |
| -      |                 |
After using strategy:

| Givens                                | Goal   |
| ------------------------------------- | ------ |
| -                                     | $P(x)$ |
| -                                     |        |
| $x=\text{(the value you decided on)}$ |        |

Form of final proof:

$$
\begin{align}
&\text{Let }x=\text{(the value you decided on)}. \\
&\quad\text{[Proof of }P(x) \text{ goes here.} \\
&\text{Thus, }\exists xP(x).
\end{align}
$$

Example 3.3.3 Prove that for every real number $x$, if $x>0$ then there is a real number $y$ such that $y(y+1)=x$.

Scratch work

| Givens | Goal                  |
| ------ | --------------------- |
| $x>0$  | $\exists y[y(y+1)=x]$ |

$$y(y+1)=x \iff y^2+y-x=0 \iff y=\frac{1\pm\sqrt{ 1+4x}}{2}$$
The steps we've used to solve for $y$ should not appear in the final proof.

$$
\begin{align}
&\text{Let }x\text{ be an arbitrary real number.} \\
&\quad\text{ Suppose }x>0. \\
&\quad\quad\text{ Let } y=\frac{-1+\sqrt{ 1+4x }}{2}. \\
&\quad\quad\quad\text{[Proof of }y(y+1)=x\text{ goes here.]} \\
&\quad\quad\text{Thus, }\exists y[y(y+1)=x]. \\
&\quad\text{Therefore }x>0\to \exists y[y(y+1)=x]. \\
&\text{Since }x\text{ was arbitrary, we can conclude that }\forall x(x>0\to \exists y[y(y+1)=x]).
\end{align}
$$

| Givens                         | Goal       |
| ------------------------------ | ---------- |
| $x>0$                          | $y(y+1)=x$ |
| $y=\frac{-1+\sqrt{ 1+4x }}{2}$ |            |

Theorem. For every real number $x$, if $x>0$ then there is a real number $y$ such that $y(y+1)=x$.

Proof. Let $x$ be an arbitrary real number, and suppose $x>0$. Let $$
y=\frac{-1+\sqrt{ 1+4x }}{2},
$$
which is defined since $x>0$. Then $$
y(y+1)=\left( \frac{-1+\sqrt{ 1+4x }}{2} \right)\cdot\left( \frac{-1+\sqrt{ 1+4x }}{2}+1 \right)=x
$$
To use a given of the form $\exists xP(x)$:
Introduce a new variable $x_{0}$ into the proof to stand for an object for which $P(x_{0})$ is true. This means that you can now assume that $P(x_{0})$ is true. Logicians call this rule of inference **existential instantiation**.

To use a given of the form $\forall xP(x)$:

You can plug in any value, say $a$, for $x$ and use this given to conclude that $P(a)$ is true. **This rule is called universal instantiation**.

Example 3.3.4. Suppose $\mathcal{F}$ and $\mathcal{G}$ are families of sets and $\mathcal{F}\cap \mathcal{G}\neq \emptyset$. Prove that $\bigcap \mathcal{F}\subseteq \bigcup \mathcal{G}$.

| Givens                      | Goal                        |
| --------------------------- | --------------------------- |
| $F\bigcap G\neq \emptyset$  | $x \in \bigcup \mathcal{G}$ |
| $x \in \bigcap \mathcal{F}$ |                             |


| Givens                                        | Goal                                |
| --------------------------------------------- | ----------------------------------- |
| $\exists A(A\in \mathcal{F}\cap \mathcal{G})$ | $\exists A\in \mathcal{G}(x \in A)$ |
| $\forall A\in \mathcal{F}(x \in A)$           |                                     |


| Givens                              | Goal                                |
| ----------------------------------- | ----------------------------------- |
| $A_{0}\in \mathcal{F}$              | $\exists A\in \mathcal{G}(x \in A)$ |
| $A_{0}\in \mathcal{G}$              |                                     |
| $\forall A\in \mathcal{F}(x \in A)$ |                                     |

Theorem. Suppose $\mathcal{F}$ and $\mathcal{G}$ are families of sets and $\mathcal{F}\cap \mathcal{G}\neq \emptyset$. Then $\bigcap \mathcal{F}\subseteq \bigcup \mathcal{G}$.

Proof. Suppose $x \in \bigcap \mathcal{F}$. Since $\mathcal{F}\cap \mathcal{G}\neq \emptyset$, we can let $A_{0}$ be an element of $\mathcal{F}\cap \mathcal{G}$. Thus, $A_{0}\in \mathcal{F}$ and $A_{0}\in \mathcal{G}$. Since $x \in \bigcap \mathcal{F}$ and $A_{0}\in \mathcal{F}$, it follows that $x \in A_{0}$. But we also know that $A_{0}\in \mathcal{G}$, so we can conclude that $x \in \bigcup \mathcal{G}$.

Example 3.3.5. Suppose $B$ is a set and $\mathcal{F}$ is a family of sets. Prove that if $\bigcup \mathcal{F}\subseteq B$ then $\mathcal{F}\subseteq \mathscr{P}(B)$.

Theorem. Suppose $B$ is a set and $\mathcal{F}$ is a family of sets. If $\bigcup \mathcal{F}\subseteq B$ then $\mathcal{F}\subseteq \mathscr{P}(B)$.

Proof. Suppose $\bigcup \mathcal{F}\subseteq B$. Let $x$ be an arbitrary element of $\mathcal{F}$. Let $y$ be an arbitrary element of $x$. But since $y\in x$ and $x \in \mathcal{F}$, by the definition of $\bigcup \mathcal{F}$, $y\in\bigcup \mathcal{F}$. But then since $\bigcup \mathcal{F}\subseteq B$, $y\in B$. Since $y$ was an arbitrary element of $x$, we can conclude that $x\subseteq B$, so $x \in \mathscr{P}(B)$. But $x$ was an arbitrary element of $\mathcal{F}$, so this shows that $\mathcal{F}\subseteq \mathscr{P}(B)$, as required.

Definition 3.3.6. For any integers $x$ and $y$, we'll say that $x$ divides $y$(or $y$ is divisible by $x$) if $\exists k\in \mathbb{Z}(kx=y)$. We use the notation $x\mid y$ to mean "$x$ divides $y$," and $x\nmid y$ means "$x$ does not divide $y$."

For example, $4\mid 20$, since $5\cdot 4 = 20$, but $4\nmid 21$.

Theorem 3.3.7. For all integers $a$, $b$, and $c$, if $a\mid b$ and $b\mid c$ then $a\mid c$.

Proof. Let $a$, $b$ and $c$ be arbitrary integers and suppose $a\mid b$ and $b\mid c$. Since $a\mid b$, we can choose some integer $m$ such that $ma=b$. Similarly, since $b\mid c$, we can choose in integer $n$ such that $nb=c$. Therefore $c=nb=nma$, so since $nm$ is an integer, $a\mid c$.

$$
\begin{align}

23.Consider the following theorem:
Incorrect Theorem. Suppose $\mathcal{F}$ and $\mathcal{G}$ are families of sets. If $\bigcup \mathcal{F}$ and $\bigcup \mathcal{G}$ are disjoint, then so are $\mathcal{F}$ and $\mathcal{G}$.

(a) What's wrong with the following proof of the theorem?

Proof. Suppose $\bigcup \mathcal{F}$ and $\bigcup \mathcal{G}$ are disjoint. Suppose $\mathcal{F}$ and $\mathcal{G}$ are not disjoint, then so are $\mathcal{F}$ and $\mathcal{G}$.

(a) What's wrong with the following proof of the theorem?
Proof. Suppose $\bigcup \mathcal{F}$ and $\bigcup \mathcal{G}$ are disjoint. Suppose $\mathcal{F}$ and $\mathcal{G}$ are not disjoint. Then we can choose some set $A$ such that $A\in \mathcal{F}$ and $A\in \mathcal{G}$. Since $A\in \mathcal{F}$, by exercise 8, $A\subseteq \bigcup\mathcal{F}$, so every element of $A$ is in $\bigcup \mathcal{F}$. Similarly, since $A\in \mathcal{G}$, every element of $A$ is in $\bigcup \mathcal{G}$. But then every element of $A$ is in both $\bigcup \mathcal{F}$ and $\bigcup \mathcal{G}$, and this is impossible since $\bigcup \mathcal{F}$ are disjoint. Thus, we have reached a contradiction, so $\mathcal{F}$ and $\mathcal{G}$ must be disjoint.

The proof implicitly assumes that $A$ contains an element. From $A\subseteq \bigcup \mathcal{F}$ and $A\subseteq \bigcup \mathcal{G}$, it follows that every element of $A$ belongs to both unions. However, this yields a contradiction only if $A\neq \emptyset$. Since $A$ may be $\emptyset$, the proof does not show that $\bigcup \mathcal{F}\cap \bigcup \mathcal{G}\neq \emptyset$. Therefore the contradiction argument is invalid.

(b) Find a counterexample to the theorem.

$\mathcal{F}=\{ \emptyset \}$. $\mathcal{G}=\{ \emptyset, \{ 1 \} \}$. $\bigcup \mathcal{F}=\emptyset$. $\bigcup \mathcal{G}=\{ 1 \}$. $\bigcup \mathcal{F}$ and $\bigcup \mathcal{G}$ are disjoint, but $\mathcal{F}$ and $\mathcal{G}$ are not disjoint.

26.(a) Comparing the various rules for dealing with quantifiers in proofs, you should see a similarity between the rules for goals of the form $\forall xP(x)$ and givens of the form $\exists xP(x)$. what is this similarity? What about the rules for goals of the form $\exists xP(x)$ and givens of the form $\forall xP(x)$.

(b) Can you think of a reason why these similarities might be expected? (Hint: Think about how proof by contradiction works when the goal starts with a quantifier.)


(a) 
To prove a goal of the form $\forall xP(x)$:

Let $x$ stand for an arbitrary object and prove $P(x)$. The letter $x$ must be a new variable in the proof. If $x$ is already being used in the proof to stand for something, then you must choose an unused variable, say $y$, to stand for the arbitrary object, and prove $P(y)$.

To use a given of the form $\exists xP(x)$:

Introduce a new variable $x_{0}$ into the proof to stand for an object for which $P(x_{0})$ is true. This means that you can now assume that $P(x_{0})$ is true. Logicians call this rule of inference **existential instantiation**.

To prove a goal of the form $\exists xP(x)$:

Try to find a value of $x$ for which you think $P(x)$ will be true. Then start your proof with "Let $x=$ (the value you decided on)" and proceed to prove $P(x)$ for this value of $x$. Once again, $x$ should be a new variable. If the letter $x$ is already being used in the proof for some other purpose, then you should choose an unused variable, say $y$, and rewrite the goal in the equivalent form $\exists yP(y)$. Now proceed as before by starting your proof with "Let $y=$ (then value you decided on)" and prove $P(y)$.

To use a given of the form $\forall xP(x)$:

You can plug in any value, say $a$, for $x$ and use this given to conclude that $P(a)$ is true. **This rule is called universal instantiation**.

Similarity between proving $\forall xP(x)$ and using $\exists xP(x)$.

In both cases, we introduce a new object into the proof and reason about it. The object is not chosen by us, and we cannot assume any properties about it beyond those given. When proving $\forall xP(x)$, the object is arbitrary; when using $\exists xP(x)$, the object is a witness whose existence is guaranteed.

Similarity between proving $\exists xP(x)$ and using $\forall xP(x)$:

In both cases, we are free to choose a particular object. To prove $\exists xP(x)$, we choose a witness and show that it satisfies $P$. To use $\forall xP(x)$, we choose any object and conclude that it satisfies $P$.

(b)
These similarities are a consequence of the duality between the quantifiers:

Quantifier Negation laws:
$\neg \exists xP(x)$ is equivalent to $\forall x\neg P(x)$.
$\neg \forall xP(x)$ is equivalent to $\exists x\neg P(x)$.

For example, when proving $\forall xP(x)$ by contradiction, we assume $\exists x\neg P(x)$, which is handled in the same way as a given existential statement. Likewise, when proving $\exists xP(x)$ by contradiction, we assume $\forall x\neg P(x)$, which is handled in the same way as a given universal statement. Thus the proof rules naturally mirror one another.
