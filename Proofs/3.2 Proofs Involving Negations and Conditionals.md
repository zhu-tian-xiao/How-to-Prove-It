# Proofs Involving Negations and Conditionals
To prove a goal of the form $\neg P$:

If possible, reexpress the goal in some other form and then use one of the proof strategies for this other goal form.

Example 3.2.1. Suppose $A\cap C\subseteq B$ and $a\in C$. Prove that $a\not\in A\setminus B$.

Scratch work

| Given                | Goal                    |
| -------------------- | ----------------------- |
| $A\cap C\subseteq B$ | $a\not\in A\setminus B$ |
| $a\in C$             |                         |

To prove the goal, we must show that it cannot be the case that $a\in A$ and $a\not\in B$. Because this is a negative goal, we try to reexpress it as a positive statement.

$a\not\in A\setminus B$ is equivalent to $\neg(a\in A\land a\not\in B)$(definition of $A\setminus B$),
which is equivalent to $a\not\in A\lor a\in B$(De Morgan's law),
which is equivalent to $a\in A\to a\in B$(conditional law).

Rewriting the goal in this way gives us:

| Givens               | Goal               |
| -------------------- | ------------------ |
| $A\cap B\subseteq B$ | $a\in A\to a\in B$ |
| $a\in C$             |                    |

We now prove the goal in this new form, using the first strategy from Section 3.1. Thus, we add $a\in A$ to our list of givens and make $a\in B$ our goal:


| Givens               | Goal     |
| -------------------- | -------- |
| $A\cap C\subseteq B$ | $a\in B$ |
| $a\in C$             |          |
| $a\in A$             |          |

The proof is now easy: from the givens $a\in A$ and $a\in C$ we can conclude that $a\in A\cap C$, and then, since $A\cap C\subseteq B$, it follows that $a\in B$.

Solution

Theorem. Suppose $A\cap C\subseteq B$ and $a\in C$. Then $a\not\in A\setminus B$.

Proof. Suppose $a\in A$. Then since $a\in C$, $a\in A\cap C$. But then since $A\cap C\subseteq B$ it follows that $a\in B$. Thus, it cannot be the case that $a$ is an element of $A$ but not $B$, so $a\not\in A\setminus B$.

To prove a goal of the form $\neg P$:
Assume $P$ is true and try to reach a contraction. Once you have reached a contraction, you can conclude that $P$ must be false.

| -      | $\neg P$ |
| -      |          |

After using strategy:


| Givens | Goal          |
| ------ | ------------- |
| -      | Contradiction |
| -      |               |
| $P$    |               |

Form of final proof:

$$
\begin{align}
&\text{Suppose }P\text{ is true.} \\

&\text{Thus, }P\text{ is false.}
\end{align}
$$

Example 3.2.2. Prove that if $x^2+y=13$ and $y\neq 4$ then $x\neq 3$.

Scratch work

The goal is a conditional statement, so according to the first proof strategy in Section 3.1 we can treat the antecedent as given and make the consequent our new goal:


| Givens     | Goal      |
| ---------- | --------- |
| $x^2+y=13$ | $x\neq 3$ |
| $y\neq 4$  |           |

This proof strategy also suggests what form the final proof should take. According to the strategy, the proof should look like this:

$$
\begin{align}
&\text{Suppose }x^2+y=13\text{ and }y\neq 4. \\
&\quad\text{[Proof of }x \neq 3\text{ goes here.]}  \\
&\text{Thus, if }x^2+y=13 \text{ and }y\neq 4 \text{ then }x\neq 3.
\end{align}
$$
The givens-goal list summarizes what we know and what we have to prove in order to solve this problem.


| Given      | Goal          |
| ---------- | ------------- |
| $x^2+y=13$ | Contradiction |
| $y\neq 4$  |               |
| $x=3$      |               |

$$
\begin{align}
&\text{Suppose }x^2+y=13\text{ and }y\neq 4. \\
&\quad\text{Suppose }x = 3.   \\
&\quad\quad\text{[Proof of contradiction goes here.]} \\
&\quad\text{Therefore }x\neq 3 \\

&\text{Thus, if }x^2+y=13 \text{ and }y\neq 4 \text{ then }x\neq 3.
\end{align}
$$
Solution

Theorem. If $x^2+y=13$ and $y\neq 4$ then $x\neq 3$.

Proof. Suppose $x^2+y=13$ and $y\neq 4$. Suppose $x=3$. Substituting this into the equation $x^2+y=13$, we get $9+y=13$, so $y=4$. But this contradicts the fact that $y\neq 4$. Therefore $x\neq 3$. Thus, if $x^2+y=13$ and $y\neq 4$ then $x\neq 3$.

To use a give of the form $\neg P$:
If you're doing a proof by contradiction, try making $P$ our goal. If you can prove $P$, then the proof will be complete, because $P$ contradicts the given $\neg P$.

Example 3.2.3. Suppose $A$, $B$, and $C$ are sets, $A\setminus B\subseteq C$, and $x$ is anything at all. Prove that if $x \in A\setminus C$ then $x \in B$.

Scratch work


| Givens                    | Goal      |
| ------------------------- | --------- |
| $A\setminus B\subseteq C$ | $x \in B$ |
| $x \in A\setminus C$      |           |


$$
\begin{align}
&\text{Suppose }x \in A\setminus C. \\
&\quad \text{Suppose }x\not\in B. \\
&\quad\quad\text{[Proof of contradiction goes here.]} \\
&\quad \text{Therefore }x \in B. \\
&\text{Thus, if }x \in A\setminus C\text{ then }x \in B. 
\end{align}
$$


| Givens                    | Goal      |
| ------------------------- | --------- |
| $A\setminus B\subseteq C$ | $x \in C$ |
| $x \in A$                 |           |
| $x\not\in C$              |           |
| $x\not\in B$              |           |

$$
\begin{align}
&\text{Suppose }x \in A\setminus C. \text{This means that }x \in A\text{ and }x\not\in C.\\
&\quad \text{Suppose }x\not\in B. \\
&\quad\quad\quad\text{[Proof of }x \in C\text{ goes here.]}  \\
&\quad\quad\text{This contradicts the fact that }x\not\in C. \\

&\quad \text{Therefore }x \in B. \\
&\text{Thus, if }x \in A\setminus C\text{ then }x \in B. 
\end{align}
$$


Solution
Theorem. Supppose $A$, $B$, and $C$ are sets, $A\setminus B\subseteq C$, and $x$ is anything at all. If $x \in A\setminus C$ then $x \in B$.

Proof. Suppose $x \in A\setminus C$. This means that $x \in A$ and $x\not\in C$. Suppose $x\not\in B$. Then $x \in A\setminus B$, so since $A\setminus B\subseteq C$, $x \in C$. But this contradicts the fact that $x\not\in C$. Therefore $x \in B$. Thus, if $x \in A\setminus C$ then $x \in B$.

To use a given of the form $\neg P$:
If possible, reexpress this given in some other form.

We said before that many strategies for using givens suggest ways of drawing inferences from the givens. Such strategies are called **rules of inference**. Both of our strategies for using givens of the form $P\to Q$ are examples of rules of inference.

To use a given of the form $P\to Q$:
If you are also given $P$, or if you can prove that $P$ is true, then you can use this given to conclude that $Q$ is true. Since it is equivalent to $\neg Q\to \neg P$, if you can prove that $Q$ is false, you can use this given to conclude that $P$ is false.

The first of these rules of inference says that if you know that both $P$ and $Q$ are true, you can conclude that $Q$ must also be true. Logicians call this rule **modus ponens(肯定前件)**.

The second rule, called **modus tollens(否定后件)**, says that if you know that $P\to Q$ is true and $Q$ is false, you can conclude that $P$ must also be false.


Example 3.2.4. Suppose $P\to(Q\to R)$. Prove that $\neg R\to(P\to \neg Q)$.


| Givens         | Goal                     |
| -------------- | ------------------------ |
| $P\to(Q\to R)$ | $\neg R\to(P\to \neg Q)$ |



| Givens         | Goal          |
| -------------- | ------------- |
| $P\to(Q\to R)$ | $P\to \neg Q$ |
| $\neg R$       |               |

$$
\begin{align}
&\text{Suppose }\neg R. \\
&\quad\text{[Proof of }P\to \neg Q\text{ goes here.]} \\
&\text{Therefore }\neg R\to(P\to \neg Q).
\end{align}
$$


| Givens         | Goal     |
| -------------- | -------- |
| $P\to(Q\to R)$ | $\neg Q$ |
| $\neg R$       |          |
| $P$            |          |

$$
\begin{align}
&\text{Suppose }\neg R. \\
&\quad\text{Suppose }P. \\
&\quad\quad\text{[Proof of }\neg Q\text{ goes here.]} \\
&\quad\text{Therefore }P\to \neg Q. \\

&\text{Therefore }\neg R\to(P\to \neg Q).
\end{align}
$$


| Givens         | Goal     |
| -------------- | -------- |
| $P\to(Q\to R)$ | $\neg Q$ |
| $\neg R$       |          |
| $P$            |          |
| $Q\to R$       |          |

$$
\begin{align}
&\text{Suppose }\neg R. \\
&\quad\text{Suppose }P. \\ 
&\quad\quad\text{Since }P\text{ and }P\to(Q\to R)\text{, it follows that }Q\to R. \\

&\quad\quad\text{[Proof of }\neg Q\text{ goes here.]} \\
&\quad\text{Therefore }P\to \neg Q. \\

&\text{Therefore }\neg R\to(P\to \neg Q).
\end{align}
$$

Theorem. Suppose $P\to(Q\to R)$. Then $\neg R\to(P\to \neg Q)$.
Proof. Suppose $\neg R$. Suppose $P$. Since $P$ and $P\to(Q\to R)$, it follows that $Q\to R$. But then, since $\neg R$, we can conclude $\neg Q$. Thus, $P\to \neg Q$. Therefore $\neg R\to(P\to \neg Q)$.

Example 3.2.5. Suppose that $A\subseteq B$, $a\in A$, and $a\not\in B\setminus C$. Prove that $a\in C$.

Theorem. Suppose that $A\subseteq B$, $a\in A$, and $a\not\in B\setminus C$. Then $a\in C$.

Proof. Since $a\in A$ and $A\subseteq B$, we can conclude that $a\in B$. But $a\not\in B\setminus C$, so it follows that $a\in C$.
